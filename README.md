# 🚀 Space Shooter

A 2D space shooter game developed in Unity using C#.

## 🎮 About the Game

Space Shooter is a 2D arcade game where the player controls a spaceship, fights enemies, avoids obstacles and completes different levels.

The game includes several playable ships with different characteristics.

## ✨ Features

- 🚀 3 playable spaceships
- ❤️ Different HP values for each ship
- ⚡ Different speed and agility characteristics
- 🎯 Enemy combat system
- 💥 Shooting mechanics
- 🗺️ Multiple levels
- 🏆 Score and kill counter
- ⏸️ Pause system
- 🎮 Ship selection menu
- 🌌 Space-themed environment

## 🛠️ Technologies

- Unity
- C#
- 2D Game Development
- Unity UI
- Git / GitHub
